# Project sources

- [Ultralytics official GitHub repository](https://github.com/ultralytics/ultralytics): code cloned into `external/ultralytics`.
- [Ultralytics YOLO11 documentation](https://docs.ultralytics.com/models/yolo11): model variants and training usage.
- [Ultralytics VisDrone documentation](https://docs.ultralytics.com/datasets/detect/visdrone): split sizes, classes, official YAML, and conversion procedure.
- [VisDrone dataset repository](https://github.com/VisDrone/VisDrone-Dataset): original dataset and annotations.
- [VisDrone challenge paper](https://openaccess.thecvf.com/content_ICCVW_2019/html/VISDrone/Du_VisDrone-DET2019_The_Vision_Meets_Drone_Object_Detection_in_Image_Challenge_ICCVW_2019_paper.html).
- [CBAM paper](https://openaccess.thecvf.com/content_ECCV_2018/html/Sanghyun_Woo_Convolutional_Block_Attention_ECCV_2018_paper).
- [P2 small-object detection reference](https://openaccess.thecvf.com/content/ACCV2024/html/Hu_A_Universal_Structure_of_YOLO_Series_Small_Object_Detection_Models_ACCV_2024_paper.html).

The VisDrone image files are downloaded into `data/VisDrone` by the official Ultralytics dataset configuration. The project does not commit downloaded images, weights, or training outputs.
